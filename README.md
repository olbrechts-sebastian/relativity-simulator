# 🚀 Relativity Simulator

An advanced interactive physics simulator visualizing Einstein’s Special Relativity and cosmic muon decay using Python and Streamlit.

Inspired by CERN-style scientific visualization systems.

---

# Features

- Interactive velocity controls
- Lorentz factor calculations
- Time dilation simulation
- Length contraction visualization
- Cosmic muon decay modeling
- Scientific graphs and dashboards
- Real-time relativistic calculations
- Futuristic physics UI

---

# Physics Concepts

This project demonstrates:

- Special Relativity
- Time Dilation
- Lorentz Transformations
- Relativistic Muon Survival
- Particle Decay
- High-Energy Physics Concepts

---

# Technologies Used

- Python
- Streamlit
- NumPy
- Matplotlib
- Plotly

## ▶ Running the Project

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the simulator:

```bash
streamlit run app.py
```
